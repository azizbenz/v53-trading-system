Date: `2026-05-03`

## Scope

This matrix records what still blocks `Shadow`, `Micro-live`, and `Live` after the Build-1 governance / DAG / smoke correction.

Current baseline:

- Build-1 is no longer a blocker.
- Build-2 is `READY`.
- Build-3, Build-4, and Build-5 remain `PARTIAL`.
- Engine C and Engine D doctrine is clean, but both remain `NOT_SHADOW_READY`.

Non-negotiable reading:

- `expected_ce_net` remains expected-only and is not realized profitability.
- `drawdown_proxy` remains diagnostic only and is not true net-equity drawdown.
- Missing cost, fill, profitability, and drawdown values are not zero.
- Engine C and Engine D cannot be treated as shadow-ready without engine-specific promotion artifacts.
