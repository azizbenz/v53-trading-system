2. `complete_enablers` is absent from the effective backtest rail. Engine C/D replay therefore misses the governed enrichment layer that should influence realism for advanced engines.

## Wiring Plan

1. **Stabilize architecture truth**: update `manifest_registry/dependency_registry.py` so the documented DAG matches the current Strategy Ladder backtest rail, or refactor the code to respect the declared DAG. Without this, every next wiring step keeps two architectures alive.
2. **Replace proxy replay seams with canonical seams**: progressively move `local_replay_runtime/strategy_ladder_detailed_replay.py` and `replay_orchestrator_execution.py` from `shadow_execution_simulator` toward canonical `execution_backbone` components for cost, fills, spread, slippage, and route realism.
3. **Wire `complete_enablers` into engine C/D replay**: import the governed enabler layer through canonical engine input composition, not through static manifests or coverage-only references.
4. **Expose shared-core runtime snapshots**: ensure backtest artifacts record which exact risk/scoring/execution/enabler versions were used so parity with Shadow can be audited.
5. **Keep the handoff one-way**: move ML/artifact packaging responsibilities out of `local_replay_runtime` where possible so `backtest_artifact_import` stays a downstream bridge instead of forming a cycle.
6. **Converge replay and Shadow gates**: reuse `protocols` gate/projection logic selectively for proof and promotion checks, but avoid importing live transport concerns into replay.
7. **Add regression coverage**: DAG check, backtest proof matrix checks, and a replay-vs-shadow parity suite should be mandatory before declaring the rail fully wired.
